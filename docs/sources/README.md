## What was saved

Most documents are normalized Markdown fetched from the raw source. Others are readable text extracted from GitHub's rendered document body. Rendered captures may come from older crawler snapshots and do not preserve all link targets or original formatting. The manifest distinguishes these formats. Fetching a page today does not establish when its content last changed.

The API documentation is [MIT licensed](https://github.com/aseprite/api/blob/main/LICENSE.txt). Its copyright and permission notice is preserved in [LICENSE.txt](aseprite-api/LICENSE.txt). This license applies to the API documentation repository; it does not establish licensing for the Aseprite executable, application source, or other documentation repositories.

[manifest.json](manifest.json) records source URLs, local paths, collection date, text line counts, and capture status. The upstream ref is `main`; an immutable commit SHA was not obtained. This is a dated research snapshot, not a byte-identical checkout. Full-text captures were checked against reported line counts where available. No failed-fetch pages have been saved as API documents.
