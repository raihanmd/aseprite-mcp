# Documentation

Start with the [repository README](../README.md) for the project and a first connection. These pages describe the maintained workflow:

- [Install](install.md): prepare the local server, extension, Codex and OpenCode entries, and pairing.
- [Use the MCP](usage.md): live revisions, saved-file jobs, animation, and review.
- [Architecture](architecture.md): code entry points and the boundary between the editor and CLI.
- [Troubleshooting](troubleshooting.md): tool discovery, pairing, editor updates, and web playback.
- [Compatibility](compatibility.md): checks to run after an Aseprite update.
- [Development](development.md): scoped tests and contribution workflow.

The [pixel-art skill](../skills/aseprite-pixel-art/SKILL.md) is the maintained art workflow; the [verification skill](../skills/verify-aseprite-mcp/SKILL.md) maps tests to user-visible behavior. The [Aseprite API source inventory](sources/README.md) is a dated, attributed research snapshot, not a replacement for current upstream documentation. Our [pixel-art research guide](research/pixel-art-deep.md) and [source map](research/pixel-art-source-map.md) preserve the principles behind the art skill.
